# Data Model: 安全运营工作流

## Design Principles

- 自动导入事实、人工运营决定和执行历史分开存储。
- 来源频道、标准频道和线路使用稳定 ID；同步只更新事实，不重建运营聚合根。
- 高风险变更先落为可审查 change set，apply 前创建 recovery point。
- `version` 是单调递增并发令牌；所有覆盖性写入检查 expected version。
- 生命周期、来源存在性、健康状态和人工锁彼此正交。
- 审计追加写入，快照正文保存在 recovery item，不复制到审计表。
- 新结构先 expand/backfill，兼容字段只在观察期通过后删除。

## Existing Entities to Extend

### Source

现有 M3U/XMLTV 来源继续分表保存。

| Field                     | Type             | Rules                                                            |
| ------------------------- | ---------------- | ---------------------------------------------------------------- |
| id                        | UUID             | Existing primary key                                             |
| name                      | string           | Required                                                         |
| enabled                   | boolean          | Disabled source cannot sync or match                             |
| priority                  | integer          | Higher value remains preferred, matching current worker behavior |
| participateInOutput       | boolean          | Effective only when enabled                                      |
| allowFallback             | boolean          | M3U only                                                         |
| freshnessThresholdMinutes | integer          | Positive; default 1,440                                          |
| lastContentFingerprint    | string nullable  | Fingerprint of last accepted immutable input                     |
| version                   | integer          | Starts at 1; increments on configuration changes                 |
| lastSyncAt/status         | timestamp/status | Existing operational facts                                       |

**Validation**:

- A disabled source can retain configuration but cannot create a sync/match preview.
- Credentials in headers or URL are never copied into audit details, task summaries or config backups.
- XMLTV readiness additionally requires a successful sync and at least one EPG channel.

### SourceChannel

Maps to existing `channels`; raw import rows remain parser evidence.

| Field                            | Type                             | Rules                                            |
| -------------------------------- | -------------------------------- | ------------------------------------------------ |
| id                               | UUID                             | Preserved across syncs                           |
| channelIdentity                  | string                           | Stable unique identity generated by parser       |
| m3uSourceId                      | UUID                             | Required while source exists                     |
| rawChannelId                     | UUID nullable                    | Current raw evidence row                         |
| displayName/group/tvgId/logo/url | source facts                     | Updated only by source sync                      |
| sourcePresence                   | `present \| missing \| conflict` | Does not change operator lifecycle               |
| firstSeenAt                      | timestamp                        | Immutable                                        |
| lastSeenAt                       | timestamp                        | Updated when identity appears                    |
| missingSince                     | timestamp nullable               | Set only when absent from accepted input         |
| sourceRevision                   | string                           | Input fingerprint/revision that last touched row |
| epgChannelId/matchType           | automatic match result           | Manual binding remains in override               |
| version                          | integer                          | Increments on source fact changes                |

**Identity rule**: `(m3uSourceId, channelIdentity)` is unique. During migration, validate whether the current globally unique `channelIdentity` already contains source scope before narrowing the constraint.

**State transitions**:

```text
present ──not found in accepted input──> missing
missing ──identity reappears───────────> present
present/missing ──ambiguous identity───> conflict
conflict ──resolved by next valid input/manual resolution──> present|missing
```

### CanonicalChannel

Existing `canonical_channels` becomes the stable output aggregate root.

| Field                          | Type                                      | Rules                                                   |
| ------------------------------ | ----------------------------------------- | ------------------------------------------------------- |
| id                             | UUID                                      | Never regenerated by EPG matching                       |
| stableKey                      | string                                    | Unique internal identity; immutable after creation      |
| standardName/group/logo/number | resolved output fields                    | Computed from override first, automatic facts second    |
| lifecycle                      | `active \| hidden \| disabled \| trashed` | Single source of lifecycle truth                        |
| lifecycleReason                | string nullable                           | Required for disabled/trashed when supplied by operator |
| trashedAt                      | timestamp nullable                        | Required in trashed state                               |
| purgeAfter                     | timestamp nullable                        | Defaults to 30 days after `trashedAt`; purge blocked earlier |
| epgChannelId/status/matchType  | resolved binding                          | Manual binding takes precedence                         |
| primaryStreamId                | UUID nullable                             | Must reference own active stream                        |
| version                        | integer                                   | Required for If-Match                                   |
| createdAt/updatedAt            | timestamp                                 | Existing                                                |

**Compatibility migration**:

- Backfill lifecycle in precedence order: `disabled=true → disabled`, else `hidden=true → hidden`, else `active`.
- Keep `hidden`, `disabled`, `outputStatus` readable during transition; new writes originate from lifecycle and update compatibility fields.
- Remove compatibility fields only in contract phase after all callers use lifecycle.

### ChannelStream

| Field               | Type               | Rules                                               |
| ------------------- | ------------------ | --------------------------------------------------- |
| id                  | UUID               | Preserved across sync/match                         |
| canonicalChannelId  | UUID               | Required parent                                     |
| sourceChannelId     | UUID nullable      | Null for fully manual stream                        |
| streamUrl           | string             | Required                                            |
| origin              | `source \| manual` | Manual streams are never removed by source sync     |
| position            | integer            | Unique and contiguous within channel, starting at 0 |
| isPrimary           | boolean            | Exactly one when channel has streams                |
| eligibleForFailover | boolean            | Defaults true for source streams                    |

| Field                     | Type              | Rules                                                                                                                      |
| ------------------------- | ----------------- | -------------------------------------------------------------------------------------------------------------------------- |
| id                        | UUID              | Preview ID                                                                                                                 |
| kind                      | operation enum    | `m3u_sync`, `epg_match`, `source_delete`, `channel_lifecycle_batch`, `channel_purge`, `backup_restore`, `recovery_restore` |

| inputFingerprint          | string            | Immutable normalized input hash                                                                                            |
| baseVersions              | object            | Target ID → expected version                                                                                               |

| warnings/blockers         | arrays            | Stable codes plus redacted display data                                                                                    |

**State transitions**:

```text
preparing → ready → applying → applied
     │        │         └──→ failed
     │        ├──→ stale
```

- Only `ready` can be applied.
- `ready` becomes `stale` when input fingerprint or any base version changes.
- Applied/failed/stale/cancelled/expired are terminal for that preview.

### SourceImportSnapshot

Immutable staging input shared by preview and apply.

| Field               | Type                                       | Rules                                  |
| ------------------- | ------------------------------------------ | -------------------------------------- |
| id                  | UUID                                       | Primary key                            |
| sourceId            | UUID                                       | Required                               |
| sourceType          | `m3u \| xmltv`                             | Required                               |
| contentFingerprint  | string                                     | Unique with source                     |
| sourceVersion       | integer                                    | Source config version used to download |
| status              | `preparing \| ready \| invalid \| expired` | Required                               |
| itemCount           | integer                                    | Parsed item count                      |
| parserVersion       | string                                     | Reproducibility metadata               |
| preparedTaskId      | UUID                                       | Origin task                            |
| createdAt/expiresAt | timestamp                                  | Required; defaults to 24-hour retention |

The staged payload is stored as normalized snapshot items in PostgreSQL and is never treated as live output. A change set references exactly one snapshot; apply never redownloads or reparses a different upstream version.

### SourceImportSnapshotItem

| Field            | Type    | Rules                                       |
| ---------------- | ------- | ------------------------------------------- |
| id               | UUID    | Primary key                                 |
| snapshotId       | UUID    | Required parent                             |
| channelIdentity  | string  | Stable parsed identity                      |

### OperationLease

Persistent business mutex.

| Field                | Type      | Rules                                             |
| -------------------- | --------- | ------------------------------------------------- |
| scopeKey             | string    | Primary key, e.g. `source:{id}` or `channel:{id}` |
| operationKind        | enum      | Current operation                                 |
| taskId/changeSetId   | UUID      | Owner                                             |
| acquiredAt/expiresAt | timestamp | Two-minute TTL by default                         |
| heartbeatAt          | timestamp | Renewed every 30 seconds                          |

Acquisition is atomic. A valid existing lease returns its TaskRef. An expired lease can be reassigned only after confirming that its referenced task is not active; cleanup never deletes a lease still owned by an active task.

### ConfigBackup

| Field                         | Type                                     | Rules                                       |
| ----------------------------- | ---------------------------------------- | ------------------------------------------- |
| id                            | UUID                                     | Primary key                                 |
| status                        | `creating \| ready \| failed \| expired` | Required                                    |
| formatVersion                 | integer                                  | Independent of app version                  |
| sourceAppVersion              | string                                   | Informational compatibility input           |

Backup bytes are not stored in PostgreSQL. `BackupObjectStorage` writes a temporary private file, verifies checksum and size, calls fsync, then atomically renames it to the opaque `storageRef`. Failed writes remove temporary files; expiry removes the object before marking metadata expired, with retryable cleanup when object deletion fails.

## Retention cleanup invariants

- Audit events are append-only and excluded from automatic retention cleanup.
- A cleanup job may expire and delete terminal change sets and source snapshots after 24 hours only when no running task, recovery point or audit reference still requires them.
- Idempotency records remain queryable for at least 24 hours; cleanup cannot shorten this window.
- Recovery points, trashed channels and configuration backups default to 30 days and expose their actual expiry/purge timestamp to the UI.
- Expired leases are reclaimed only after the referenced task is confirmed non-active.

## Referential Integrity

```text
Source ──< SourceChannel ──< CanonicalChannelMember >── CanonicalChannel
              └──< SourceChannelIdentityAlias
                                  │                           │
SourceChannel ──0..1 ChannelOverride                        ├──< ChannelStream
                                                              └──0..1 ChannelFailoverPolicy

OperationChangeSet ──< OperationChangeItem
        ├── SourceImportSnapshot ──< SourceImportSnapshotItem
        │
        ├──0..1 RecoveryPoint ──< RecoveryPointItem
        ├── prepare/apply Task
        └──< AuditEvent

ScheduledJobConfig ──< Task ──< retry/recovery Task
Task / ChangeSet / RecoveryPoint ──< AuditEvent
Business Aggregate ──< OutboxEvent
ConfigBackup ── Task
```

## Migration and Backfill Rules

1. Add nullable/defaulted columns and new tables without changing old reads.
2. Backfill `version=1`, source presence, lifecycle and stream positions deterministically.
3. Build canonical members from `mergedFromIds`; unresolved identities produce a migration conflict report and do not alter output.
4. Validate exactly one primary per channel and repair only unambiguous cases; ambiguous cases become blockers.
5. Shadow-run new diff/membership resolution against fixed 10k data and current production-shaped data.
6. Enable new preview/apply writes per source; maintain compatibility fields from lifecycle during observation.
7. Disable old delete/recreate worker paths after recovery and preservation gates pass.
8. Remove compatibility fields and JSON membership only in a later contract migration.
